First InstallTrace preview for Windows x64. Download InstallTrace.exe; Python is bundled.

- Before/after snapshots of selected files, registry startup/uninstall keys, services and tasks.
- Comparison filters, offline reports and uninstall leftover candidates.
- No automatic deletion or installer execution.
- Includes SHA256SUMS.txt and the executable smoke-test results.

Published only after Linux/Windows regression tests and a Windows executable smoke test pass.
The hosted test machine is Windows Server 2025; consumer Windows 10/11 validation is still
recommended. This preview is unsigned and may trigger Windows SmartScreen. Check the
publisher/source and hash; this is not an antivirus or installer-attribution engine.
